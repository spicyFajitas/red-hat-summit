# Setting up Red Hat OpenShift in your lab or homelab

If you’ve ever wanted to install Red Hat OpenShift on premise but didn’t know how to get started, or you’re a homelabber wanting to explore Red Hat OpenShift further without spinning up big, expensive cloud instances, this session is for you. We’ll provide a quickstart walkthrough of installing Red Hat OpenShift on physical, virtual, or cloud instances, including:

Comparing on-premise versus cloud or managed cloud installations.
Configuring your network(s), Dynamic Host Configuration Protocol (DHCP), Domain Name System (DNS), and HAProxy instance.
Using Network File System (NFS) as a storage resource
Running the installation from a bootstrap node.
Post-installation configuration. 
Examples will emulate a multi-network setup to help you learn how to complete the installation in an enterprise setting. (Note that the information covered in this session is also applicable to OKD, the upstream project for Red Hat OpenShift.)
