The state of Ansible Core in 2026

In this session, Ansible Core leads will talk about what's new for 2026, including a sneak peek at in-progress features. We’ll explore several features expected in Ansible 2.21, including:

Register projections.
Support for third-party fact injection plug-ins.
Post-quantum cryptography (PQC) improvements for Ansible vault and rpm_key.
Conditional deprecation warnings backport to mirror version 2.19 and later.
Microsoft Windows improvements:
Connection resiliency.
PowerShell Remoting Protocol (PSRP) performance improvements.
PowerShell 7 support.
