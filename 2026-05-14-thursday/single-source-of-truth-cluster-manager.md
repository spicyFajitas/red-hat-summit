# Single source of truth: T-Mobile's unified GitOps strategy for cluster management

Managing a distributed, bare-metal multicluster fleet of Red Hat OpenShift clusters—dedicated to running everything from telco workloads, spanning legacy Virtualized Network Functions (VNFs) and modern Containerized Network Functions (CNFs), to mission critical IT workloads—requires a single, unified automation strategy.

This session details T-Mobile's approach for automating OpenShift lifecycle management at scale, embracing Red Hat best practices around Red Hat Advanced Cluster Management for Kubernetes as the central control plane and Red Hat OpenShift GitOps (Argo CD) as the declarative execution engine.

We will cover:

Day 0 (provisioning): Establishing the initial bare-metal Red Hat Advanced Cluster Management hub cluster (which serves as the control plane) and the Git repository as the single source of truth for the entire multicluster environment

Day 1 (bootstrap): Bootstrapping the hub with core Red Hat Advanced Cluster Management and Argo CD operators to create the minimal control plane for Day 2 automation

Day 2 (continuous management): Using GitOps and Red Hat Advanced Cluster Management governance policies for continuous cluster lifecycle management and compliance

Attendees will learn how to unify their automation tooling to achieve auditable, scalable infrastructure as code (IaC) for hybrid environments. We will share best practices for Git repository structure and achieve a single, auditable IaC source of truth for a heterogeneous on-premises environment.
